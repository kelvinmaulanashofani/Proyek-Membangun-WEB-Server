# 🌐 Building a Web Server

A simple learning project focused on setting up and configuring a web server using **Nginx**, **Apache**, and **Node.js** on **Linux**.  
This project was created to understand how web servers work, how to configure a reverse proxy, and how to manage basic network security.

---

## ⚙️ Technologies Used
- **Operating System:** Kali Linux
- **Web Servers:** Nginx, Apache
- **Backend:** Node.js
- **Tools:** netstat, curl, systemctl, ufw

---

## 🎯 Objectives
- Learn basic web server configuration and deployment  
- Understand reverse proxy setup using Nginx  
- Practice managing multiple web services on Linux  
- Strengthen knowledge of network and server fundamentals  

---

## 🧠 Learning Outcome
Gained practical experience in configuring and testing a web server environment for personal development and IT networking practice.
