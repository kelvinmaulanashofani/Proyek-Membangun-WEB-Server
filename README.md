# 🌐 Membangun Web Server

Proyek pembelajaran sederhana yang berfokus pada proses instalasi dan konfigurasi **web server** menggunakan **Nginx**, **Apache**, dan **Node.js** pada **Kali Linux**.  
Proyek ini dibuat untuk memahami cara kerja web server, penerapan **reverse proxy**, serta pengelolaan dasar keamanan jaringan.

---

## ⚙️ Teknologi yang Digunakan
- **Sistem Operasi:** Kali Linux  
- **Web Server:** Nginx, Apache  
- **Backend:** Node.js  
- **Tools:** netstat, curl, systemctl, ufw  

---

## 🎯 Tujuan
- Mempelajari konfigurasi dan penerapan web server dasar  
- Memahami pengaturan **reverse proxy** menggunakan Nginx  
- Berlatih mengelola beberapa layanan web di sistem Linux  
- Memperkuat pemahaman tentang dasar jaringan dan server  

---

## 🧠 Hasil Pembelajaran
Mendapatkan pengalaman praktis dalam konfigurasi dan pengujian web server menggunakan Kali Linux untuk pengembangan kemampuan di bidang jaringan dan administrasi server.
